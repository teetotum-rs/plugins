# Counter

Turn the knob and the number on the glass follows, one per detent; a tap sets it back to zero.

It is the smallest face here that asks for a right: `Rights::KNOB` hands the detents to the face
instead of the firmware. Build it with `sh build.sh`, as the [template](../../template/README.md)
describes.
